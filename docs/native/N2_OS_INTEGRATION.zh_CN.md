# Native ELF 集成 — Passport OS 1.0.34

已完成共享 C3 Loader、受保护可执行池、二进制包校验、内置发布者信任、AppManager 生命周期、回调 ABI、SDK 编译/模板/检查及 Native Hello。保留 Lua 和声明式应用。这是初始集成范围，不代表 N2–N6 全部完成；原生网络、音频、存储、异步任务、RTOS 和 XIP 尚未实现。

## Flash 和内存

| 测量项 | 字节 |
|---|---:|
| OTA 应用固件 | 2,120,064 |
| 首次安装合并固件 | 2,251,136 |
| 每个 OTA 分区（保持不变） | 2,621,440 |
| 永久保留的可执行池 | 16,384 |
| Native Hello ELF 文件 | 2,512 |
| Native Hello 加载跨度／实测池峰值 | 1,472 |
| 应用退出后池占用 | 0 |
| 链接静态 RAM | 185,876 |

两种镜像都小于十进制 2.5 MB。优化使用 `-Os`、关闭宽泛 ELF 符号导出，并复用现有绘图和会话。保留完整 TLS 根证书、中文字库、Lua、音频及断言。同功能 `-Og` 对照为 2,315,088 字节，节省 195,024 字节（8.42%）；不能用旧缓存构建直接作同条件比较。16 KiB 池永久预留，退出后归还池内空间，不归还通用堆。通用 EXEC 堆仍为零，Loader 使用专用池。内存保护、锁和监控保持开启；日志 `protection=0` 表示校验返回 ESP_OK。

Native Hello 运行时通用空闲堆约 82 KB，退出约 84 KB；网络并发使此值波动。链接 RAM 不是运行时堆峰值；执行 Lua 后的全局最低堆不能算作 Native 单独消耗。

## 验证与硬件结果（2026-10-29）

- 仓库静态检查、宿主回归和固件／合并镜像门禁通过。Native 校验包含 2,500 个 Python/C 变异与截断一致性样本，以及 ASan/UBSan 下 20,000 次变异。
- 已知 USB ESP32-C3 已启动 1.0.34，OTA 状态 VALID。仅写入 0x20000 应用分区，保留分区表、NVS、应用包及数据；另一个分区仍保留 1.0.33。
- 签名 Native Hello 安装、启动、注入 OK 单击更新计数、退出及重新启动均通过。标准视口 240×272。Lua 小智也启动退出通过，不代表其远端服务或音频已验证。
- 第一轮 1,000 次生命周期均成功，总堆下降 132 字节；第二轮 1,000 次成功且漂移为零。最终精确固件再跑 1,000 次，全部成功，漂移为零，耗时 75.214466 秒。每次退出池占用为零，峰值 1,472 字节；保留报告首次波动，不声称所有测试绝对零漂移。
- 最终固件强制执行 100 次绘图／生命周期循环，全部通过，耗时 21.589561 秒，总堆漂移 -112 字节。该时间包含会话切换，不能作为帧率指标。
- 正确签名但返回 ABI 2 的临时应用被 ABI 1 运行时拒绝：launch FAIL、错误可读，628 字节临时池占用完全回收。测试应用已删除，随后 Native Hello 正常启动。
- 自动化检查不证明实体 LCD 观感、实体按键手感或原生网络／音频可用；当前尚未导出原生网络／音频 API。

## 信任边界和后续工作

Native 是高权限机器码，不具备 Lua 沙箱隔离。只接受内置 OS 发布者；新增 Lua 发布者不会获得原生权限。进入上游 Loader 前检查 ELF 长度、加载段、入口、重定位及未定义符号。宿主回调检查权限和配额，但恶意高权限代码能够绕过协作规则，不声称支持不可信原生代码。

下一阶段先为通用异步网络／音频建立取消、生命周期和资源限额测试，再扩展版本化宿主表。小智协议及认证留在应用侧。扩大发布范围前补充实体显示／按键验收和更长时间 Lua/Native 混合测试。[开发规范](../developer/native-apps.zh_CN.md)。

首次静态测试发现模拟器 WebSocket mock 的旧缺陷：短文本未补 NUL，旧 hello 尾部被误读，导致小智音频错误测试随机失败（修正前 20 次中 15 次通过）。已为发送回显和 hello 回复补齐结束符，修正后重复执行原有回归 100 次。此改动仅影响宿主，不改变已测固件。

已测应用镜像已发布至本机 `build/system-updates/local-update/`，版本 1.0.34，构建号 2026102901。8765 端口本地 HTTP 服务的索引和镜像长度、SHA-256 均已验证。筛选脱敏测试结果 (`integration-results.txt`; 本地诊断，不公开)。
