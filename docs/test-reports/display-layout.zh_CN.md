# Display Manager 与应用布局验收

## 构建与宿主检查

- D0 硬件来源：ST7788P3 纵向 240×320、UP/DOWN/OK 三个 ADC 按键；ESP-IDF5.5.3、LVGL9.5.0。
- Manifest 支持 standard/fullscreen 和 portrait，拒绝未知模式/方向。
- 宿主布局测试检查精确区域和视口裁切。
- Lua 用例覆盖 `get_viewport`、两种尺寸、声明式绑定、非法模式、绘图裁切、图形/游戏/音频事件。
- 完整验证门通过，包含 Wi-Fi 表单解析器测试。
