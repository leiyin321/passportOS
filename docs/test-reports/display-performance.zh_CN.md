# 显示延迟验收 — 2026-10-29

固件：Passport OS 1.0.45，ESP32-C3、240×320 RGB565、无 PSRAM。优化前使用 OS 1.0.41。原始串口记录保留在忽略目录 `local/native_xiaozhi/`，本文仅提供计时。

## 方法与测量

在主页通过正常前台输入队列注入 DOWN 单击，随后立即请求串口界面快照，读取到 `PASSPORT DONE`。优化前五次，优化后十次。测量软件命令／锁等待延迟，不包含液晶发光响应、物理按键消抖或 OK 双击判断窗口。

| 测量（毫秒） | 范围 | 平均 |
|---|---:|---:|
| 优化前单击后界面查询 | 923.88–928.56 | 925.35 |
| 优化后单击后界面查询 | 86.30–116.07 | 103.45 |
| 优化后单击命令确认 | 1.20–1.92 | 1.48 |

显示事件探针记录输入到下一次刷新就绪为 85.11–114.18 毫秒，对应绘制耗时 83.01–112.02 毫秒。已有刷新可能先结束，因此不能仅凭该探针证明变化像素已到达面板。全屏切换、应用正文重绘可能比主页焦点切换慢。

## 修改

- 缓存已应用的主题和未变化的文字，消除不必要的根节点／样式失效及重复排版。
- 主页焦点仅使旧、新卡片区域失效；自绘卡片／设置跳过当前 LVGL 裁剪区域以外的项目。
- LVGL 最长空闲等待降至 50 毫秒。单个四行 DMA 缓冲 1,920 字节，LVGL 栈 5 KiB、池 16 KiB；无 PSRAM 的 C3 保持单缓冲。
- 有界批量交付网络消息，按既有帧率／视图变化合并绘制。WebSocket 发送使用独立有界的 3 KiB 工作任务。
- UP／DOWN 仍在松开时立即单击；OK 保留 180 毫秒单双击判断，避免双击先触发确定。按住说话仍使用原始按下／松开事件。
