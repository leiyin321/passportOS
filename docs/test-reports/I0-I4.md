# Icon/assets baseline and first device results

I0: ESP-IDF5.5.3, LVGL9.5.0 exactly pinned in main/idf_component.yml/dependencies.lock.
Pre-assets OS app:1,753,920B. Shared DMA display buffer19,200B, static LVGL pool24KiB,
no PSRAM, no new app/full-screen image framebuffer. Existing Montserrat14/20 includes system symbols.
Configuration: LV_CACHE_DEF_SIZE=0, LV_BIN_DECODER_RAM_LOAD=n. Native indexed decoder supports
per-row ARGB8888 output; it is reused rather than adding an image engine.

I1 host PASS:14 unique semantic IDs and fallback. Four custom A1 masks cost4x72=288B pixels;
other entries reference existing LVGL font symbols. Native glyphs/masks live in read-only firmware,
with small persistent descriptors. No full icon font corpus added.

I2 host PASS:12 compiler tests plus native format tests. Fixed Pillow11.3.0/CairoSVG2.8.2;
SVG is rendered only on the host. External SVG resources/entities are denied. Generated fixtures:
A1 24x24=96B (72 pixels+24 wrapper); A4=312B; I4 48x48=1240B
(1152 pixels+64 palette+24 wrapper); I8=3352B. Equivalent RGB56548x48 wrapper size4632B,
so I4 saves73.23%. Thirty I4 assets:37,200B; signed grid package44,292B.

I3/I4 first device PASS: PAP1 counter install/offload/reinstall still restores data after the streaming
PAP2 refactor. USB and Store packages are staged to Flash, signature/hash checked in bounded chunks;
code and metadata are loaded, whole asset bundles are not. PAI1 headers are validated and translated
to lv_image_dsc_t; the custom wrapper is never handed to LVGL.
