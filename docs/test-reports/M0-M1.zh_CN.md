# M0/M1 实验记录 — 2026-10-25

M0 构建 PASS；上游及基线固件哈希见[审计](../hardware-audit.md)。
只读识别 ESP32-C3 rev1.1 / 8MB；完整原始 Flash 备份位于私有忽略文件
`local/original-flash.bin`，校验值在 `local/original-flash.sha256`。
设备原分区不同于上游：factory 0x10000/4MiB、cardid NVS 0x410000/16KiB、
storage SPIFFS 0x420000/2MiB。均已备份，重分区将在备份完成后进行。
首次整片读取在 93% 时发生 USB 短数据错误；改为可恢复的 512KiB 分块后完成 16/16。
曾有并发刷写尝试被串口排他锁拒绝，未写入；后续串口操作串行执行。

资源测量、作用域生命周期及输入事件队列。
