# Passport OS 系统闹钟

闹钟归 Passport OS 所有。MiniApp 没有创建、修改或关闭系统闹钟的 SDK 接口。

## 操作方式

打开 **Settings → 闹钟**。闹钟默认关闭，默认时间为 07:00。详情页会显示“正在设置”以及
当前选中的字段：小时或分钟会在时间中用方括号标出，启用状态会显示为 `[关闭]` 或
`[开启]`。闹钟关闭时，进入详情会自动选中启用状态；按上下键即可开启或关闭。开启后再
进入详情会从小时开始。按上下键调整当前项，短按 OK 依次切换小时、分钟、启用状态；
停止操作 1.5 秒后自动保存到 `osconfig` NVS。设置列表会显示时间和启用状态。系统使用
24 小时本地时间，每日重复。

到达设定分钟时，Passport OS 会关闭前台 MiniApp、点亮屏幕并循环播放扬声器提示音。按
任意键停止提示并返回主界面。本版本暂不支持稍后提醒。

## 调度与生命周期

调度器使用现有 SNTP 系统时钟，固定时区为 `Asia/Shanghai`（UTC+08:00）。系统时间无效时
不会调度。每个本地日历日最多触发一次，避免主循环在同一分钟重复触发。重启后系统恢复
已保存闹钟，并在时间同步有效后开始调度。时区固定，因此不处理夏令时切换。

提示音由独立 FreeRTOS worker 负责，并调用现有 BSP 音频编解码器/扬声器 API。停止提醒时
会请求 worker 退出并暂停编解码器。闹钟接管音频前会先停止应用音频 worker。

## 限制与验证

提醒要求设备有电且 Passport OS 正在运行。当前深睡眠仍是独立的 RTC 定时器/GPIO 唤醒
demo，没有接入闹钟截止时间，因此不承诺深睡后按闹钟时间唤醒。真机需验证设定时间、重启
持久化、声音、任意键关闭、前台应用中断和音频资源回收。

纯调度和时间调整逻辑由 `tests/test_alarm.c` 宿主测试覆盖。
