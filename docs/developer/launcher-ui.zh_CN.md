# 启动器界面

240x320 主界面使用 Apps、Store、Settings 三张图文卡片，分别进入应用库、应用商店和设置。
UP/DOWN 按阅读顺序循环选中，单击 OK 进入/确认，双击 OK 返回主界面。
每张卡片包含共享语义图标、简短名称和辅助说明。选中卡片具有强调边框、填色图标底座与勾选标记，
不只依赖颜色表示选中。Wi-Fi 和电量位于顶部，操作提示位于底部。

布局：内容区域 (12,80)、216x200；卡片按三项布局。图像全部复用现有
Montserrat14/20 和 System Icon Registry。一个常驻 LVGL 绘制对象绘制三张卡片，
不增加位图资源、自定义字体、动画定时器或全屏帧缓冲。
LVGL 锁保护显示用焦点快照和可见性切换。授权对话框隐藏卡片，应用和其他系统页保留各自布局。

用户此前已确认文字版启动器显示与实体按键正常。新的卡片版本更新固件后需要重新确认视觉效果；
自动化真机检查见当前执行检查点。

自动化真机检查 PASS：四个入口、200 次焦点切换、应用退出返回主界面。
焦点切换期间显示帧由 28 增至 462，空闲堆 82,344 到 82,260 字节（-84），最大连续块保持
73,728 字节。退出网格应用后应用资源为零。固件 1,768,784 字节、增加 944 字节；静态 BSS
增加 8 字节。构建/宿主/真机检查 PASS；新版布局的实体视觉确认待反馈。
