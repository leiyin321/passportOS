# Native 城市电台

`org.passport.city-radio` 0.1.2 是独立实现的 Native ABI 2 应用，功能参考公开的[城市之声玩法说明](https://ai-passport.folotoy.cn/plays/65/)。不包含原固件、源码、美术或广播录音。源码：[应用](../../examples/city_radio/main.c)、[目录](../../examples/city_radio/catalog.c)。

## 安装与操作

先通过“设置 → 系统更新”升级到 **Passport OS 1.0.59**，再从本机 App Store 安装城市电台。旧系统不支持新增媒体扩展及权限。Wi-Fi 配网、网络校时、熄屏与闹钟仍由 OS 管理。收听不需要麦克风授权，也不依赖 Mac 转码代理。

| 页面 | UP / DOWN | OK | 长按 OK |
|---|---|---|---|
| 收听 | 切换当前城市上一／下一台；长按上下键调音量 ±5 | 暂停／继续；失败后重试 | 菜单 |
| 菜单／列表 | 移动选择，列表分页 | 打开／选择 | 返回收听；电台列表返回城市 |
| 城市搜索 | 选择 A–Z、搜索或删除 | 输入字母／搜索／删除 | 收听 |
| 时钟 | 任意短按／长按唤醒收听 | 唤醒 | 唤醒 |

双击 OK 保持 OS 返回主页行为；UP／DOWN 不增加双击。唤醒时钟的第一次按键不会换台或暂停。音量修改本次开机的系统媒体音量，不影响闹钟音量；持久化默认音量在 OS 设置中调整。

提供北京、上海、广州、深圳、杭州、长沙、成都七城，每城两个目录位置。搜索匹配城市拼音首字母前缀：BJ、SH、GZ、SZ、HZ、CS、CD。首版为内置目录，不是完整在线城市库，也不自动定位。成都第二项明确标记为全国备用。广播平台可能改变或移除台源；HTTP 成功不代表此刻播出的节目名称已人工核实。

历史最多保留十个不重复电台，最近收听置顶。成功播放后记录，重启恢复已保存电台。风格与历史使用应用私有存储，数据格式为 schema 1，依赖稳定目录索引；扩展时追加台源，不重排索引。两种原创界面分别展示调谐刻度／频谱和蓝色磁带机。动画表示播放状态，不是真实 FFT 测量。时钟读取 OS 时间，显示北京时间 UTC+8；收听页闲置三十秒进入时钟，播放继续。

定时停止循环：关闭 → 15 → 30 → 60 分钟 → 关闭。到期停止播放，仅本次会话有效，不创建系统闹钟。退出应用停止收听，暂不支持后台播放。系统闹钟响铃前会关闭前台应用。

## 通用 OS 媒体扩展

引入 [passport_native_media.h](../../sdk/native/include/passport_native_media.h)。C3 上 ABI 2 核心前缀仍为 80 字节，HID 前缀 96 字节，追加媒体扩展后 120 字节；转换指针前必须检查完整大小。既有 Native ABI 1／2 及 Lua 契约保持兼容。声明 `audio.playback` 与 `network.fetch`，首版仅允许可信 Native ABI 2。不要在同一应用会话中混用此播放所有者与麦克风／Opus 采集。

| 方法 | 契约 |
|---|---|
| `media_play(url)` | 复制 MP3 URL 后排队（HTTPS，或通过 `audio.http` 允许的公开 HTTP）；1 表示接受，0 表示忙或拒绝；不在调用中同步执行 DNS、网络或音频 I/O |
| `media_stop()` | 请求异步停止；状态退出缓冲／播放／停止中后，才能再次播放 |
| `media_state()` | 0 空闲，1 缓冲，2 播放，3 停止中，4 失败，5 流结束 |
| `media_volume(percent)` | -1 查询；0…100 修改本次开机的系统媒体音量；其他值返回 -1 |
| `wall_time()` | Unix 秒数；OS 尚未校时返回 0 |
| `battery_percent()` | 只读 0…100；不可用返回 -1 |

首版仅支持 MP3 裸流，不支持 AAC、HLS/M3U8、播放列表或 DRM。应用负责城市目录、URL、重试、历史与 UI；OS 负责传输、解码、PCM 混音、I2S、系统媒体音量及回收。应用 0.1.2 声明显式 `audio.http` 权限，使用无认证的公开 HTTP 广播；普通 fetch／WS 保留既有安全策略。网络接收复用既有任务，独立播放任务消费固定分块池，每块最多 512 字节压缩数据；启动／断流恢复前完整预缓冲。不能同时发起另一条 HTTP／WS 请求。应用轮询状态，不向工作线程传递 ELF 回调。

初始 URL 与每次重定向均执行既有精确域名白名单、公网地址／DNS 固定及 TLS 证书校验；最多三次重定向，目标在白名单内放行，否则拒绝。HTTPS／443 仍为默认；OS 1.0.56 新增显式 `audio.http` 例外，要求可信 Native ABI 2、`audio.playback` 与 `network.fetch`，仅允许精确白名单域名、公网 IPv4 及 HTTP／80。拒绝私网／本机地址、URL 用户凭据及 HTTP 查询字符串；媒体播放不提供自定义认证头或请求体。HTTP 音频不加密，仅用于不含秘密的公开广播。应用声明 `lhttp.qingting.fm` 和 `lhttp.qtfm.cn`。请求 `Icy-MetaData: 0` 关闭元数据；仍强制交错 ICY 元数据的服务端会被拒绝。每次请求上限为二十四小时、512 MiB，套接字超时三秒。每次选台／恢复最多尝试三次，耗尽后通过 OK 重试。

MP3 帧组装缓冲限制为 1,536 字节，跳过有界 ID3 标签，验证 Layer III 帧头，连续 64 KiB 未同步即失败。支持单／双声道 8–48 kHz、16 位输出；双声道混合到单声道扬声器。[解码器来源](../../components/passport_mp3/README.zh_CN.md)与[测试报告](../test-reports/city-radio.zh_CN.md)说明内存及验证限制。

## 构建与恢复开发

```sh
PYTHONPATH=sdk python -m passport native build examples/city_radio
PYTHONPATH=sdk python -m passport pack examples/city_radio --key <private.pem> --public sdk/publisher-public.pem -o <city-radio.pap>
./tools/validate.sh
```

签名私钥和原始台源采样不进版本库。继续开发时查看测试报告及现有交接检查点。设备验收必须检查真实节目声音、实体按键、中文字形、双声道混音、重复换台／暂停／退出、定时到期、闹钟打断、断网重连、堆内存恢复和 C3 解码耗时。

## 当前缓冲及音质配置（OS 1.0.59 / 应用 0.1.2）

音质菜单提供流畅（默认，服务端 `/24k.mp3`）和标准（`/64k.mp3`）。北京音乐的流畅源实测为 32 kbit/s，不能根据 URL 名称保证实际码率。独立的私有 `quality` 键保存音质，不改变原有 schema 1 电台、历史和样式数据。播放中切换会重新连接，暂停时保持暂停。

公开 HTTP 初始分配 32 个独立的 512 字节块，解码器与 DAC 初始化后，在扩容时保留 14 KiB 空闲堆的条件下最多扩到 64 块，实际深度取决于运行内存。HTTPS 使用 16 块。网络/播放任务栈分别为 6/4 KiB。仅输出 BSP 初始化避免分配闲置麦克风 DMA，每次 PCM 写入最多 240 个单声道采样。

短网络读取先拼满块，只有 EOF 才提交不足一块的尾部，保证队列深度代表真实压缩数据量而非读取次数。开始及续播等待池填满，以启动延迟换取对突发电台数据的容忍度，无法保证任意远端中断下连续播放。Mac 实测同一源数据突发之间最长间隔 5.64 秒。播放期间临时关闭 Wi-Fi 省电，结束恢复原模式。解码工作区在传输分配前预热并复位，退出回收任务、解码器及全部块。实际资源测量及待验收项目见测试报告。
